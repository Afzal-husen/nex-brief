<task type="auto">
  <name>Task 1: Define Epistemic Pydantic Schemas and Category Taxonomy</name>
  <files>backend/app/models/extraction.py, backend/app/models/__init__.py</files>
  <read_first>.planning/phases/02-extraction-grounding-engine/02-CONTEXT.md, backend/app/models/__init__.py</read_first>
  <action>
    Create `backend/app/models/extraction.py` implementing the domain models per decisions D-08, D-09, D-16, D-17, D-18, D-19:
    
    1. `FactCategory(str, Enum)`:
       - `SCOPE = "scope"`
       - `TIMELINE = "timeline"`
       - `BUDGET = "budget"`
       - `TECH_STACK = "tech_stack"`
       - `TARGET_AUDIENCE = "target_audience"`
       - `CONSTRAINTS = "constraints"`
       - `INTEGRATIONS = "integrations"`
       - `OTHER = "other"`

    2. `QuoteSpan(BaseModel)`:
       - `start_char: int`
       - `end_char: int`
       - `line_start: int`
       - `line_end: int`

    3. `ConfirmedFact(BaseModel)`:
       - `id: str = Field(default_factory=lambda: str(uuid.uuid4()))`
       - `category: FactCategory`
       - `statement: str` (clear, concise declarative fact)
       - `source_quote: str` (verbatim substring quote from transcript)
       - `speaker: str | None = None` (speaker attribution if present)
       - `spans: list[QuoteSpan] = Field(default_factory=list)` (all occurrence spans in transcript)

    4. `InferredPoint(BaseModel)`:
       - `id: str = Field(default_factory=lambda: str(uuid.uuid4()))`
       - `category: FactCategory`
       - `statement: str`
       - `source_fact_ids: list[str] = Field(default_factory=list)` (IDs of ConfirmedFacts supporting this deduction)
       - `rationale: str` (explanation of why the deduction follows from client statements)
       - `status: str = "inferred"`

    5. `UnknownGap(BaseModel)`:
       - `id: str = Field(default_factory=lambda: str(uuid.uuid4()))`
       - `category: FactCategory`
       - `missing_information: str`
       - `impact_level: Literal["high", "medium", "low"]`
       - `suggested_question: str` (seeding Phase 3 follow-up generation)

    6. `UnverifiedCandidate(BaseModel)`:
       - `statement: str`
       - `failed_quote: str`
       - `speaker: str | None = None`
       - `reason: str`

    7. `RawFactCandidate(BaseModel)`:
       - Schema used by Groq structured output: `statement: str`, `source_quote: str`, `speaker: str | None`, `category: FactCategory`

    8. `RawInferenceCandidate(BaseModel)`:
       - `statement: str`, `rationale: str`, `category: FactCategory`, `supporting_fact_indices: list[int] = Field(default_factory=list)`

    9. `RawUnknownCandidate(BaseModel)`:
       - `missing_information: str`, `impact_level: Literal["high", "medium", "low"]`, `suggested_question: str`, `category: FactCategory`

    10. `RawExtractionPayload(BaseModel)`:
        - `facts: list[RawFactCandidate]`
        - `inferences: list[RawInferenceCandidate]`
        - `unknowns: list[RawUnknownCandidate]`

    11. `ExtractionResult(BaseModel)`:
        - `confirmed_facts: list[ConfirmedFact] = Field(default_factory=list)`
        - `inferred_points: list[InferredPoint] = Field(default_factory=list)`
        - `unknown_gaps: list[UnknownGap] = Field(default_factory=list)`
        - `unverified_candidates: list[UnverifiedCandidate] = Field(default_factory=list)`

    Update `backend/app/models/__init__.py` to re-export all extraction models.
  </action>

  </verify>

  <name>Task 2: Implement Groq LLM Client Factory with Fallback and Structured Output</name>
  <files>backend/app/core/llm.py</files>
  <read_first>backend/app/core/config.py, .planning/phases/02-extraction-grounding-engine/02-CONTEXT.md</read_first>
  <action>
    Create `backend/app/core/llm.py` implementing the Groq client integration per decisions D-01, D-02, D-03, D-04:
    
    1. Define `get_groq_llm(model: str = "llama-3.3-70b-versatile", temperature: float = 0.0, timeout: int = 30, max_retries: int = 3) -> ChatGroq`:
       - Loads `settings.groq_api_key`
       - Returns `ChatGroq(model_name=model, groq_api_key=settings.groq_api_key or "dummy-key", temperature=temperature, request_timeout=timeout, max_retries=max_retries)`
    
    2. Define `get_extraction_llm_with_fallback()`:
       - Primary: `get_groq_llm(model="llama-3.3-70b-versatile", temperature=0.0)`
       - Fallback: `get_groq_llm(model="llama-3.1-8b-instant", temperature=0.0)`
       - Returns `primary.with_fallbacks([fallback])`
    
    3. Define `get_structured_extraction_client()`:
       - Returns `get_extraction_llm_with_fallback().with_structured_output(RawExtractionPayload)`
    
    4. Provide support for custom override / mock injection so unit tests can swap the runnable with a mock callable or mock ChatGroq without making external HTTP requests.
  </action>

  </verify>
