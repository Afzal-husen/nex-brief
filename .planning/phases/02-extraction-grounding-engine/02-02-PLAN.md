  <name>Task 1: Implement Deterministic Verbatim Grounding Verifier</name>
  <files>backend/app/services/grounding.py</files>
  <read_first>backend/app/models/extraction.py, .planning/phases/02-extraction-grounding-engine/02-CONTEXT.md</read_first>
  <action>
    Create `backend/app/services/grounding.py` implementing verbatim substring verification per decisions D-05 through D-15:
    
    1. Define line calculation helper `calculate_line_numbers(text: str, start_char: int, end_char: int) -> tuple[int, int]`:
       - `line_start = text.count('\n', 0, start_char) + 1`
       - `line_end = text.count('\n', 0, end_char) + 1`
       - Returns `(line_start, line_end)`

    2. Define `find_quote_spans(transcript_text: str, quote: str) -> list[QuoteSpan]`:
       - Check for ellipsis (`...` or `…`). If present, reject immediately per D-10 (returns empty list).
       - Strip surrounding quotes or whitespace if present.
       - Exact match: search all occurrences of `quote` in `transcript_text` using `re.finditer(re.escape(quote))` (D-08, D-14).
       - If no match found: case-insensitive match using `re.finditer(re.escape(quote), re.IGNORECASE)` (D-13). For each match, use the matched span from the actual transcript.
       - If still no match found: whitespace-collapsed match (D-06). Collapse multiple spaces and newlines in both `quote` and `transcript_text` to locate the substring boundaries.
       - For every found occurrence, calculate `start_char`, `end_char`, `line_start`, `line_end` and return `list[QuoteSpan]`.

    3. Define `verify_candidate_facts(transcript_text: str, candidates: list[RawFactCandidate], llm_client=None) -> tuple[list[ConfirmedFact], list[UnverifiedCandidate]]`:
       - For each candidate fact:
         - Find quote spans using `find_quote_spans(transcript_text, candidate.source_quote)`.
         - If spans found: construct `ConfirmedFact(category=candidate.category, statement=candidate.statement, source_quote=candidate.source_quote, speaker=candidate.speaker, spans=spans)`.
         - If spans NOT found and `llm_client` provided: trigger single targeted re-prompt (D-05) asking LLM to provide the corrected exact verbatim quote or mark unsupported. If corrected quote yields valid spans, add as `ConfirmedFact`; otherwise append to `unverified_candidates` with `reason="Quote not found in transcript after retry"`.
         - If spans NOT found and no retry available: append to `UnverifiedCandidate` with `reason="Quote not found in transcript text"`.
       - Deduplicate identical quotes (D-12): if two facts share identical `source_quote`, merge into one `ConfirmedFact` consolidating all distinct spans.
       - Zero-fact handling (D-15): return verified facts and unverified candidates cleanly.
  </action>

<task type="auto">
  <name>Task 2: Build Two-Node LangGraph Extraction State Machine and Service</name>
  <files>backend/app/graph/__init__.py, backend/app/graph/extraction.py, backend/app/services/extraction.py</files>
  <read_first>backend/app/core/llm.py, backend/app/services/grounding.py, .planning/phases/02-extraction-grounding-engine/02-CONTEXT.md</read_first>
  <action>
    1. Create `backend/app/graph/__init__.py`.
    2. Create `backend/app/graph/extraction.py` implementing the LangGraph pipeline per decisions D-20, D-21, D-22, D-23, D-24, D-25:
       - Define `ExtractionState(TypedDict)`:
         - `transcript_id: str`
         - `project_id: str`
         - `transcript_text: str`
         - `raw_payload: RawExtractionPayload | None`
         - `confirmed_facts: list[ConfirmedFact]`
         - `inferred_points: list[InferredPoint]`
         - `unknown_gaps: list[UnknownGap]`
         - `unverified_candidates: list[UnverifiedCandidate]`
         - `retry_count: int`
         - `errors: list[str]`

       - Node `extract_knowledge(state: ExtractionState)`:
         - Formulates extraction system prompt instructing Groq to extract client-stated facts with exact verbatim quotes, deductions as inferences with rationale, and scoping unknowns with suggested questions.
         - Calls `get_structured_extraction_client()` (D-24).
         - Returns `{"raw_payload": result}`.

       - Node `verify_grounding(state: ExtractionState)`:
         - Extracts raw facts from `state["raw_payload"]`.
         - Invokes `verify_candidate_facts(transcript_text, raw_facts, llm_client)`.
         - Processes raw inferences: maps `supporting_fact_indices` to the generated `ConfirmedFact.id`s, instantiating `InferredPoint` models with `source_fact_ids` (D-17).
         - Processes raw unknowns: instantiates `UnknownGap` models (D-18).
         - Zero-fact check (D-15): if `len(confirmed_facts) == 0`, append an `UnknownGap(category=FactCategory.OTHER, missing_information="Transcript contained no verifiable project requirements", impact_level="high", suggested_question="Could you provide an overview of the core goals and requirements for this project?")`.
         - Returns updated `confirmed_facts`, `inferred_points`, `unknown_gaps`, `unverified_candidates`.

       - Build graph DAG: `StateGraph(ExtractionState)`:
         - Add node `extract_knowledge`
         - Add node `verify_grounding`
         - Add edge `START -> extract_knowledge`
         - Add edge `extract_knowledge -> verify_grounding`
         - Add edge `verify_grounding -> END`
         - Compile graph supporting checkpointer parameter.

    3. Create `backend/app/services/extraction.py` (D-26):
       - Define `run_extraction_pipeline(transcript_id: str, transcript_text: str, project_id: str = "", checkpointer=None, llm_client=None) -> ExtractionResult`:
         - Normalizes transcript text using `normalize_transcript_text(transcript_text)` to ensure consistent character indexing.
         - Connects `SqliteSaver` checkpointer if none supplied (`SqliteSaver.from_conn_string(settings.database_url)`).
         - Compiles graph with checkpointer.
         - Invocates graph with `thread_id = transcript_id` config (D-23).
         - Returns `ExtractionResult(confirmed_facts=..., inferred_points=..., unknown_gaps=..., unverified_candidates=...)`.
  </action>
