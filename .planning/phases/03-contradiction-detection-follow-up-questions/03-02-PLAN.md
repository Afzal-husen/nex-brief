<task type="auto" id="03-02-02">
<name>Implement Prioritized Question Generator Node</name>
<description>
Create `backend/app/graph/clarification.py` with `generate_clarifications_node(state)`:
1. Prioritization ranking heuristic:
   - Rank 1 candidates: `Contradiction`s with `severity == "direct_conflict"`.
   - Rank 2 candidates: `UnknownGap`s with `impact_level == "high"`.
   - Rank 3 candidates: `Contradiction`s with `severity == "tension"`.
   - Rank 4 candidates: `UnknownGap`s with `impact_level == "medium"`.
   - Rank 5 candidates: `UnknownGap`s with `impact_level == "low"`.
2. Select top items up to a strict cap of 5 (and at least 3 if total available candidates >= 3).
3. If LLM refinement is needed, invoke `get_structured_clarification_client()` on selected targets to generate crisp, actionable phrasing, rationale, and 2-3 suggested options.
4. Fallback generator: If LLM is not called or offline, construct deterministic `ClarificationQuestion` items directly from `suggested_question` in `UnknownGap` and `conflict_rationale` in `Contradiction`.
5. Assign priority integers 1..N and return `{"clarification_questions": questions}`.
</description>
