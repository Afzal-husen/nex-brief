<task type="auto" id="03-01-02">
<name>Implement Contradiction Detection Node with Verbatim Grounding</name>
<description>
Create `backend/app/graph/contradiction.py` implementing `detect_contradictions_node(state)`:
1. Formulates prompt containing `normalized_text` and list of verified `ConfirmedFact`s.
2. Invokes Groq with structured output bound to `RawContradictionPayload`.
   - Add helper `get_structured_contradiction_client()` in `backend/app/core/llm.py` with mock support (`set_mock_contradiction_client()`).
3. Iterates over candidates:
   - Verifies `quote_a` via `find_quote_spans(normalized_text, candidate.quote_a)`.
   - Verifies `quote_b` via `find_quote_spans(normalized_text, candidate.quote_b)`.
   - If either quote fails or contains ellipsis (`...`), adds to `unverified_contradictions`.
   - If both pass, checks if quotes match existing `state["facts"]` to populate `fact_id_a` / `fact_id_b`, creates `Contradiction`, and adds to `contradictions`.
4. Returns state update dict with `contradictions` and `unverified_contradictions`.
</description>
