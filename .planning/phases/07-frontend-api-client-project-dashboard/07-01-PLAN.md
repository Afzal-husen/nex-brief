<task id="07-01-01" wave="1">
<name>Define TypeScript API models, client, and structured error handling</name>
<description>
Create `frontend/src/lib/api/types.ts`:
- Define `ProjectStatus` = `'created' | 'analyzing' | 'awaiting_clarification' | 'synthesizing' | 'ready_for_review' | 'approved'`.
- Define `Project` interface (`id`, `title`, `description`, `status`, `created_at`, `updated_at`).
- Define `ProjectCreatePayload` (`title: string`, `description?: string | null`).
- Define `ApiErrorResponse` interface.

Create `frontend/src/lib/api/client.ts`:
- Define custom `ApiError` class extending `Error` (`status: number`, `detail: string`, `code?: string`).
- Read `NEXT_PUBLIC_API_URL` environment variable, defaulting to `http://localhost:8000/api/v1`.
- Implement `apiClient` with methods:
  - `projects.list()`: `GET /projects` -> `Project[]`
  - `projects.get(id: string)`: `GET /projects/${id}` -> `Project`
  - `projects.create(payload: ProjectCreatePayload)`: `POST /projects` -> `Project`
  - `projects.delete(id: string)`: `DELETE /projects/${id}` -> `{ status: string; id: string }`
  - `health.check()`: `GET /health` -> `{ status: string; app: string }`
- Include robust error parsing for both JSON error responses and network offline failures.
</description>

</task>

<task id="07-01-02" wave="1">
<name>Build SWR data fetching hooks with smart polling</name>
<description>
Create `frontend/src/lib/api/hooks.ts`:
- Implement `useProjects()` hook:
  - Wraps `useSWR('/projects', () => apiClient.projects.list())`.
  - Calculates dynamic `refreshInterval`: returns `2500` ms if any project in the list has status `'analyzing'` or `'synthesizing'`, otherwise returns `0` (revalidating on window focus).
  - Exposes `projects`, `isLoading`, `error`, and `mutate`.
- Implement `useProject(id?: string)` hook:
  - Wraps `useSWR(id ? `/projects/${id}` : null, () => apiClient.projects.get(id!))`.
  - Dynamically polls every `2500` ms while project status is `'analyzing'` or `'synthesizing'`.
  - Exposes `project`, `isLoading`, `error`, and `mutate`.
</description>

6. `Toast.tsx`:
