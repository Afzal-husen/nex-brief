    - Function `normalize_transcript_text(raw_text: str) -> tuple[str, list[str], int, int]`:
      1. Validate `len(raw_text) <= MAX_TRANSCRIPT_LENGTH`; raise `ValueError` if exceeded.
      2. Normalize line endings (`\r\n` -> `\n`).
      3. Strip trailing whitespace per line while preserving speaker labels (regex pattern matching `^[A-Za-z0-9 _-]+:`).
      4. Collapse 3+ consecutive newlines to 2 newlines (paragraph separation).
      5. Extract detected unique speaker names/labels.
      6. Calculate `character_count` and `word_count`.
      7. Return `(normalized_text, detected_speakers, character_count, word_count)`.
  </action>

    - `POST /api/v1/projects`: Creates project from `ProjectCreate`, returns `ProjectRead` (201 Created).
    - `GET /api/v1/projects`: Lists all projects ordered by `created_at desc`, returns `list[ProjectRead]`.
    - `GET /api/v1/projects/{id}`: Retrieves project by UUID, returns `ProjectRead` or 404 `{"detail": "Project not found", "code": "PROJECT_NOT_FOUND"}`.
    - `DELETE /api/v1/projects/{id}`: Deletes project and cascaded records, returns `{"status": "deleted", "id": id}` or 404.

    Create `backend/app/api/transcripts.py`:
    - `POST /api/v1/projects/{id}/transcripts`:
      - Validates project exists (404 if missing).
      - Accepts raw text payload (`{"raw_text": "..."}`).
      - Normalizes text via `normalize_transcript_text()`. Returns 422 if >100,000 characters.
      - Marks previous transcripts for this project as `is_active=False`.
      - Saves new `Transcript` record with `is_active=True` and returns `TranscriptRead` (201 Created).
    - `GET /api/v1/projects/{id}/transcripts`:
      - Returns active `TranscriptRead` for project, or 404 if no transcript uploaded yet.

    Include both routers in `backend/app/main.py`.
  </action>
