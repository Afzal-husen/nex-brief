<objective>
Build the interactive contradiction resolution and gap clarification interface (`UI-04`) at `/projects/[id]/clarify`. Features 1-click contradiction resolution cards, suggested option chips for unknown gaps, slide-over transcript context drawer, live progress tracking, and synthesis resumption handshake with FastAPI.

Purpose: Empowers operators to make grounded editorial decisions on ambiguous transcript points and conflicting claims before generating the project brief.
Output: API client extension, context extractor, resolution cards, transcript drawer, and full clarification page.
</objective>
