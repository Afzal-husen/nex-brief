<task id="05-01-02" wave="1">
<title>Implement Workflow Service and POST /projects/{id}/analyze Endpoint</title>
<description>
Create `backend/app/services/workflow.py`:
- `trigger_project_analysis(db, project_id)`:
  - Fetches project and latest transcript. If no transcript, raises 400.
  - If project status is `analyzing` or `synthesizing`, raises 409.
  - Updates status to `analyzing`.
  - Runs graph compiled with `interrupt_before=["synthesize_brief"]` with thread_id `project:{project_id}:transcript:{transcript_id}`.
  - Sets project status to `awaiting_clarification`.
  - Returns extracted facts, contradictions, and prioritized questions.
Create `backend/app/api/workflow.py`:
  - `POST /projects/{id}/analyze` router endpoint.
Mount router in `backend/app/main.py`.
Add test in `backend/tests/test_workflow_api.py`.
</description>
