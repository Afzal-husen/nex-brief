<title>Implement POST /projects/{id}/clarify Resumption Endpoint</title>
<description>
In `backend/app/services/workflow.py`:
- `resume_project_with_clarifications(db, project_id, clarifications)`:
  - Validates project status is `awaiting_clarification` (else 409).
  - Updates project status to `synthesizing`.
  - Re-opens checkpointer for `thread_id`.
  - Updates graph state: `graph.update_state(config, {"user_clarifications": [...]}, as_node="generate_clarifications")`.
  - Resumes execution: `final_state = graph.invoke(None, config=config)`.
  - Extracts `draft_brief` and `critique_report`.
  - Upserts `ProjectBriefRecord` with `draft_brief_json` and `critique_report_json`.
  - Sets project status to `ready_for_review`.
  - Returns `draft_brief` and `critique_report`.
In `backend/app/api/workflow.py`:
  - Implement `POST /projects/{id}/clarify` endpoint accepting `list[UserClarification]`.
Add integration test in `backend/tests/test_workflow_api.py`.

<task id="05-02-02" wave="2">
<title>Implement GET /projects/{id}/brief and POST /projects/{id}/approve Endpoints</title>
<description>
In `backend/app/services/workflow.py`:
- `get_project_brief_details(db, project_id)`:
  - Retrieves `ProjectBriefRecord` for `project_id` (404 if not found).
  - Returns combined view with draft brief, approved brief, critique report, and approval timestamp.
- `approve_project_brief(db, project_id, edited_brief=None)`:
  - Checks if brief record exists (else 400).
  - If edited_brief provided, saves it as the final approved brief; otherwise promotes draft brief to approved brief.
  - Sets `ProjectBriefRecord.status = "approved"` and stamps `approved_at`.
  - Sets `Project.status = "approved"`.
  - Returns approved brief details.
In `backend/app/api/workflow.py`:
  - Implement `GET /projects/{id}/brief`.
  - Implement `POST /projects/{id}/approve`.
Add tests in `backend/tests/test_workflow_api.py` testing complete end-to-end user journey:
analyze -> interrupt -> clarify -> inspect brief -> edit & approve.
</description>
