<task id="06-01-02" wave="1">
<name>Implement Diff Engine and integrate into brief approval hook</name>
<description>
Create `backend/app/services/diff_engine.py`:
- Implement `compute_section_diffs(draft_brief: dict[str, Any], approved_brief: dict[str, Any]) -> list[dict[str, Any]]`:
  - Iterates over all 11 predefined sections.
  - Extracts section content from draft and approved dictionaries.
  - Uses `difflib.unified_diff` to generate unified diff strings.
  - Uses `difflib.SequenceMatcher.ratio()` to calculate similarity ratio (1.0 if identical).
  - Determines `has_changed = (draft_content != approved_content)` and `character_delta = len(approved) - len(draft)`.
In `backend/app/services/workflow.py` inside `approve_project_brief`:
- Call `compute_section_diffs` between `draft_brief` and `approved_brief`.
- Persist `CorrectionLog` objects in SQLite within the approval transaction.
</description>
