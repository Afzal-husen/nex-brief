<task type="auto" name="brief-api-types-and-client">
<action>
1. In `frontend/src/lib/api/types.ts`:
   - Add `BriefSection` interface (`key`, `title`, `content`, `source_fact_ids`, `inference_ids`, `supporting_clarification_ids`).
   - Add `CritiqueIssue` interface (`id`, `section_key`, `issue_type`, `severity`, `explanation`, `suggested_fix`).
   - Add `CritiqueReport` interface (`score`, `summary`, `issues`).
   - Add `ProjectBrief` interface (`id`, `project_id`, `transcript_id`, `created_at`, `sections`, `full_markdown`).
   - Add `BriefResponse` interface (`project_id`, `status`, `draft_brief`, `approved_brief`, `critique_report`, `approved_at`).
   - Add `ApproveRequest` interface (`edited_brief?: Record<string, any>`).
   - Add `ApproveResponse` interface (`project_id`, `status`, `approved_at`, `approved_brief`).
2. In `frontend/src/lib/api/client.ts`:
   - Add `apiClient.workflow.getBrief(projectId: string): Promise<BriefResponse>`.
   - Add `apiClient.workflow.approve(projectId: string, payload?: ApproveRequest): Promise<ApproveResponse>`.
3. In `frontend/src/lib/api/hooks.ts`:
   - Add `useBrief(projectId: string | null)` SWR hook returning `{ briefData, isBriefLoading, briefError, mutateBrief }`.
