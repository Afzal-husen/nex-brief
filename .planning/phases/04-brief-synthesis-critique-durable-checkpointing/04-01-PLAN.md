<objective>
Define domain Pydantic schemas for the 11-section project brief, user clarifications, and critique reports. Implement the `synthesize_brief` node to generate all 11 sections grounded in confirmed facts and clarifications, and the `critique_brief` node to audit draft briefs for ungrounded claims or neglected constraints.

Purpose: Delivers requirements BRIEF-01 and BRIEF-02 to turn extracted knowledge into verifiable, grounded briefs with automated self-critique.
Output: Pydantic brief schemas in `backend/app/models/brief.py`, synthesis and critique nodes in `backend/app/graph/nodes/`, and hermetic unit tests.
</objective>

<task id="04-01-01" wave="1">
<title>Define Brief, Clarification, and Critique Pydantic Schemas</title>
<description>
Create `backend/app/models/brief.py` with:
- `SectionKeyEnum` / section key constants for the 11 sections: `executive_summary`, `objectives_success_criteria`, `target_audience`, `scope_of_work`, `out_of_scope`, `technical_architecture`, `assumptions_inferences`, `risks_contradictions`, `budget_commercials`, `timeline_milestones`, `outstanding_questions`.
- `BriefSection`: `key: str`, `title: str`, `content: str`, `source_fact_ids: list[str]`, `inference_ids: list[str]`, `supporting_clarification_ids: list[str]`.
- `ProjectBrief`: `id: str`, `project_id: str`, `transcript_id: str`, `created_at: datetime`, `sections: dict[str, BriefSection]`, `full_markdown: str`.
- `UserClarification`: `question_id: str`, `resolved_text: str`, `resolved_by: str = "user"`.
- `CritiqueIssue`: `id: str`, `section_key: str`, `issue_type: Literal["ungrounded_claim", "contradiction_neglect", "missing_constraint", "vague_deliverable"]`, `severity: Literal["critical", "warning", "info"]`, `explanation: str`, `suggested_fix: str`.
- `CritiqueReport`: `score: int = Field(ge=0, le=100)`, `summary: str`, `issues: list[CritiqueIssue]`.
- `RawBriefSection` and `RawBriefPayload` for Groq structured output.
Re-export in `backend/app/models/__init__.py` and extend `ExtractionState` in `backend/app/graph/state.py`.
Add unit tests in `backend/tests/test_brief_models.py`.
</description>

<task id="04-01-02" wave="1">
<title>Implement 11-Section Brief Synthesis Node</title>
<description>
Create `backend/app/graph/nodes/synthesize_brief.py`:
- Formats confirmed facts, inferences, contradictions, unknowns, and user clarifications into prompt blocks.
- Clarifications are placed in dedicated block `'USER CLARIFICATIONS & RESOLUTIONS'` with instructions treating user answers as authoritative facts overriding transcript ambiguities.
- For sections lacking information (e.g. budget, timeline), instructs LLM to output `"Not discussed in discovery call"` with linked unknowns/questions rather than hallucinating details.
- Calls Groq with structured output (`RawBriefPayload`) using fallback model logic.
- Assembles `ProjectBrief` containing all 11 sections and compiles `full_markdown` header + sections.
- Returns update to `ExtractionState` with `draft_brief: ProjectBrief`.
Re-export in `backend/app/graph/nodes/__init__.py`.
Add unit tests in `backend/tests/test_brief_synthesis.py` mocking the Groq structured output client.
</description>

<task id="04-01-03" wave="1">
<title>Implement Automated Critique Audit Node</title>
<description>
Create `backend/app/graph/nodes/critique_brief.py`:
- Compares `draft_brief` against confirmed facts, inferences, active contradictions, and transcript text.
- Structured output target: `CritiqueReport` checking for `ungrounded_claim`, `contradiction_neglect`, `missing_constraint`, and `vague_deliverable`.
- Calculates quality score (0-100) based on issue counts and severities.
- Attaches `critique_report: CritiqueReport` to `ExtractionState` without modifying the brief (advisory transparency).
Re-export in `backend/app/graph/nodes/__init__.py`.
Add unit tests in `backend/tests/test_critique.py`.
</description>
