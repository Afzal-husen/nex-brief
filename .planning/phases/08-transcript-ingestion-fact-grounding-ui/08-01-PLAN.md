<task type="auto" name="add-backend-analysis-endpoint">
<action>
1. In `backend/app/api/workflow.py`, add `GET /projects/{id}/analysis` endpoint returning `AnalyzeResponse`.
   - Query project by ID; raise 404 if missing.
   - Fetch latest transcript for project from SQLite. If no transcript, return empty `AnalyzeResponse`.
   - Formulate `thread_id = f"project:{id}:transcript:{transcript.id}"` and `config = {"configurable": {"thread_id": thread_id}}`.
   - Use `get_checkpointer()` to instantiate the LangGraph graph, call `graph.get_state(config)`, and extract `values`.
   - Return `AnalyzeResponse` populated with `confirmed_facts`, `inferred_points`, `contradictions`, `unknown_gaps`, and `clarification_questions`.
2. In `backend/tests/test_analysis_endpoint.py`, write tests:
   - `test_get_analysis_project_not_found`: verify 404 for nonexistent project.
   - `test_get_analysis_no_transcript`: verify empty state when project has no transcript.
   - `test_get_analysis_with_checkpoint`: verify retrieval of extracted facts and questions from an analyzed project.
</action>

<task type="auto" name="extend-frontend-api-and-parser">
<action>
1. In `frontend/src/lib/api/types.ts`, declare:
   - `Transcript`, `TranscriptCreate`, `ConfirmedFact`, `InferredPoint`, `Contradiction`, `UnknownGap`, `ClarificationQuestion`, `AnalyzeResponse`.
2. In `frontend/src/lib/api/client.ts`, add methods to `api.transcripts` and `api.workflow`:
   - `api.transcripts.create(projectId: string, data: TranscriptCreate): Promise<Transcript>`
   - `api.transcripts.list(projectId: string): Promise<Transcript[]>`
   - `api.workflow.getAnalysis(projectId: string): Promise<AnalyzeResponse>`
   - `api.workflow.analyze(projectId: string): Promise<AnalyzeResponse>`
3. In `frontend/src/lib/api/hooks.ts`, implement:
   - `useTranscripts(projectId: string | undefined)`
   - `useAnalysis(projectId: string | undefined)`
4. In `frontend/src/lib/utils/transcript-parser.ts`, implement:
   - `parseTranscriptFile(file: File): Promise<string>` supporting `.txt`, `.md`, `.vtt`, `.srt`. For VTT/SRT, strip timestamp headers and cue markers.
   - `getTranscriptMetrics(text: string): { charCount: number; wordCount: number; speakers: string[] }` extracting character count, word count, and speaker prefixes matching `^([A-Za-z0-9 _-]+):\s*`.
